## 실도면 (scripts/verify-table.ts)
`npx vite-node scripts/verify-table.ts [경로...]` (기본 `D:\CADView_도면`, 없으면 skip). TABLE 포함 .dxf 마다 원문 `0/ACAD_TABLE` 개수와 파싱 개수(ENTITIES + BLOCKS) 비교, NaN·음수 행열·셀 수≠행x열·행높이/열폭 개수 불일치 리포트. 예외나 개수 불일치가 있으면 종료코드 1.

## 발견 사항
- 수정: 셀 뒤(엔티티 끝)의 XDATA 가 버려지던 문제 → 1001 을 만나면 헤더 파서(XData 스니펫 포함)에 위임.
- 수정: 그룹 3 텍스트 청크 무시 → 셀 텍스트·CELL_VALUE 모두 2/3 을 청크로 연결. 청크 연결을 `String()` 으로 명시.
- 현재 동작 문서화(T-O-04, T-S-07): 헤더 구간의 중복 단일값/미지 코드에서 공통 `createParser` 가 멈춘다. 다른 엔티티와 같은 공통 동작이라 TABLE 에서만 바꾸지 않음.
- 범위 밖(참고): BLOCKS 파서는 `0 ENDBLK` 뒤 `100 AcDbBlockEnd` 가 없으면 이후 섹션을 다 소비한다(T-M-04 는 실제 DXF 처럼 AcDbBlockEnd 를 넣음).
